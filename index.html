Verify a download

When the beta ships, open its entry in GitHub Releases. Download the package for your system, SHA256SUMS, and SHA256SUMS.minisig from that same entry.

  1. Save the Mini public key (mini.pub). Compute its SHA-256 digest and compare it with the value below. Before trusting the key, confirm this digest through the maintainer’s separately managed channel.
    2fdfe0b47e9cba1ffad73362ec8e612a3cef487f87b1928b75299ecf52109659
  2. In the download folder, authenticate the checksum list with Minisign.
    minisign -Vm SHA256SUMS -p mini.pub
  3. Once the signature verifies, use the SHA-256 command in the release notes. Match the entire digest to the entry for your exact filename before opening the package.
